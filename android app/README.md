# Android App Production APKs

This folder contains the compiled, production-ready release APKs for the **Campus ERP Biometric Attendance System**.

---

## Which file should I install?

### 1. `CampusERP-arm64-v8a-release.apk` (Recommended - 46.0 MB)
* **Best for**: 99% of all modern Android smartphones and tablets (ARM 64-bit devices).
* **Install**: Download directly onto your Android device and tap to install.

### 2. `CampusERP-armeabi-v7a-release.apk` (38.7 MB)
* **Best for**: Older 32-bit Android smartphones.

### 3. `CampusERP-Universal-release.zip` (53.8 MB)
* **Best for**: Universal fat binary supporting all device architectures in one package.
* **Install**: Unzip to obtain `app-release.apk`, then install.

---

## Installation Instructions
1. Download the APK onto your Android phone.
2. If prompted, allow **"Install unknown apps"** in your device Settings.
3. Open the app and grant **Camera** and **Location** permissions.
